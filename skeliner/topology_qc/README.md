# SWC Topology QC Toolkit

## Overview

This repository contains a collection of analysis and visualization tools for evaluating the **topological quality of neuronal SWC skeletons**.

The goal is **not** to modify SWC files. Instead, the toolkit analyzes an existing skeleton and identifies locations where the biological topology may be questionable.

Examples include:

- partner swaps
- premature terminations
- missing continuations
- anomalous branching junctions
- suspicious high-degree nodes
- disconnected local topology
- unusually complex branch corridors

All analyses operate on the original SWC without altering it.

---

## Motivation

A skeleton may satisfy graph-theoretic constraints while still containing biologically implausible topology resulting from segmentation gaps, merge errors, tracing ambiguity, or skeletonization artifacts.

This toolkit provides an analysis layer that helps identify those locations for visualization and manual review.

---

## Design Philosophy

The project follows a layered architecture.

The core analysis is performed once, and higher-level tools build upon it.

```
                  SWC
                   │
                   ▼
        build_graph_context()
                   │
                   ▼
         NodeClassifier.py
      (core topology analysis)
                   │
      ┌────────────┼─────────────┐
      ▼            ▼             ▼
FindAnomalous  Neighborhood  BuildTopology
    Regions       Tree       GraphViewer
```

The original SWC is never modified.

---

## Repository Contents

### NodeClassifier.py

Core reusable topology analysis engine.

Responsibilities include:

- graph construction
- neighborhood analysis
- component decomposition
- distal component measurements
- branch pairing analysis
- node feature extraction
- suspicious node classification

This module contains no visualization or file-writing logic.

---

### CheckSWCTree.py

Basic graph integrity verification.

Checks:

- exactly one root
- E = N − 1
- tree connectivity

This establishes that later analyses are studying **biological topology**, not graph-theoretic failures.

---

### FindAnomalousRegions.py

Whole-tree topology scan.

Outputs:

- anomalous_nodes.csv
- anomalous_regions.csv
- interactive HTML visualization

Suspicious nodes are grouped into connected regions for easier inspection.

---

### NeighborhoodTree.py

Interactive local debugger.

Displays:

- upstream chain toward the soma
- downstream neighborhood
- suspicious nearby nodes
- local topology around a selected node

Useful for understanding why a node was classified as anomalous.

---

### BuildTopologyGraphViewer.py

Constructs a contracted topology graph.

Outputs:

- topology_nodes.csv
- topology_edges.csv
- topology_summary.txt
- topology_graph.html

Degree-2 chains are collapsed into corridors while preserving biologically meaningful branchpoints and terminals.

This provides a simplified representation for topology inspection without modifying the original SWC.

---

## Typical Workflow

1. Verify that the SWC is a valid tree.

```
CheckSWCTree.py
```

2. Scan the entire neuron.

```
FindAnomalousRegions.py
```

3. Visualize the contracted topology.

```
BuildTopologyGraphViewer.py
```

4. Inspect individual locations.

```
NeighborhoodTree.py --node <SWC node id>
```
